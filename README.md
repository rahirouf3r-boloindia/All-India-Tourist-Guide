# 🌍 Universal Travel Link - India Destination Website

A production-ready, lightweight interactive travel website engineered specifically for international tourists and expats visiting India. It aggregates essential local travel utilities into a fast, zero-installation single-page website dashboard.

🚀 **Live Website URL:** [https://github.io](https://github.io)

---

## 📱 Website Key Features

*   **Essential Directory Router:** Fast-access navigation grid linking visitors directly to official Indian service platforms (Uber, Ola, PhonePe, Paytm, Zomato, and IRCTC).
*   **Live Forex Calculator:** Real-time financial component converting global currencies (USD, EUR, GBP, AED, SGD, AUD) into Indian Rupees (INR) using live, dynamic API feeds.
*   **AI Translation Hub:** Dual-mode web speech translator mapping global languages to regional Indian languages (Hindi, Bengali, Tamil, Telugu, Marathi) with built-in text-to-speech audio playback.
*   **Smart Infrastructure Maps:** Integrated interactive mapping widgets pre-loaded with local coordinate data for transit networks, verified currency bureaus, heritage sites, and medical centers.
*   **Web Camera QR Scanner:** In-browser hardware camera utility built via safe browser permission layers to read local UPI transactional payment structures seamlessly.

---

## 🛠️ Web Architecture & Technology Stack

This website is intentionally built using clean, lightweight source code to guarantee lightning-fast load speeds over weak mobile internet connections in airports or train stations.

*   **Frontend Design:** Semantic HTML5, CSS3 Variables Architecture (Fully mobile-responsive layout)
*   **Core Logic:** Vanilla JavaScript (ES6 Client-side)
*   **External Scripting:** Secure `html5-qrcode` engine loaded via verified CDN
*   **Mapping Interface:** Google Maps Embedded Web API
*   **Financial Engine:** Open Exchange Rates Engine REST API

---

## 🚀 How to Launch the Code Locally

Because this website runs entirely client-side, it requires zero backend servers to run.

1. Clone or download this repository.
2. Open the `index.html` file inside any desktop or mobile web browser.
3. *Note:* Modern web security requires an active secure connection (`https://` like GitHub Pages) or a local testing environment (`http://localhost`) to grant the web camera access for the QR scanner.
